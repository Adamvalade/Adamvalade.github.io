Cadence — Music Social App

TypeScript / Next.js / FastAPI / PostgreSQL / Redis / Docker

Full-stack music review and discovery platform.

  • Built a FastAPI and PostgreSQL backend with authentication, album reviews, ratings, lists, and social features.
  • Developed a Next.js frontend for music discovery, album pages, user profiles, and social activity.

Megatron Chess — C++ Chess Engine

C++ / Node.js / JavaScript / UCI / Docker

Playable web chess application powered by a custom C++ engine.

  • Built a chess engine in C++ using bitboards for efficient move generation, legal move handling, and position evaluation.
  • Implemented alpha-beta search, iterative deepening, quiescence search, move ordering, and Zobrist-based transposition tables.
  • Integrated the UCI engine with a browser chess interface through a Node.js API.
Play Chess GitHub

ForgeQueue — Distributed Job Queue

Python / Redis / Docker / REST API

Fault-tolerant distributed background job processing system.

  • Built a Redis-backed distributed job queue supporting at-least-once delivery, worker leasing, crash recovery, retries, and dead-letter queues.
  • Implemented delayed job scheduling and exponential backoff using Redis sorted sets.
  • Designed idempotency, deduplication, processing locks, and REST APIs for reliable queue operations.
